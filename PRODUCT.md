# Neyra Android
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
Confirmed: Kotlin and Jetpack Compose. Native Android app, local network first.
## Users
Neyra users moving between their computers and phone.
## Product Purpose
Discover computers running Neyra, choose one to address, save spoken notes,
and receive reminders on phone and desktop.
## Operating Context
Computers and phone share a trusted local network. Pairing is explicit.
## Capabilities and Constraints
No cloud relay in this version. Desktop must run the companion bridge.
Cached reminders may notify offline; new changes require a connection.
## Brand Commitments
Neyra name, public repository, MIT license matching desktop.
## Product Principles
Keep the destination visible. Preserve local processing. Make connection state honest.


## Confirmed companion extensions

QR scanning and a visible desktop companion entry; conversations heard on the
phone; desktop-engine transcription; durable offline note/audio capture; Android
text/link sharing; home-screen capture widget; notification actions and recurring
reminders; cached note search. Keep the existing native visual system and explicit
target selection. Local-network first remains confirmed; no remote relay is added.
