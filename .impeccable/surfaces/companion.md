# Companion shell — Quiet clarity

Native Kotlin / Jetpack Compose. Direct implementation requested using Apple Design.
The current direction supersedes the previous forest, ink and warm-surface designs.

Capture: centered small neyra wordmark beside a computer dropdown, followed by one
rounded-square Speak control. All secondary capture actions live in Compose.
Five destinations: Capture, Compose, PCs, Inbox, Notes. Phone dock becomes a tablet
rail; content width is constrained. Light/dark neutral surfaces and blue actions.

Compose preserves modes, editable shared/transcribed text, explicit original-target
guards, pending recordings, provider disclosures, playback/Stop and reminder repeat.
PCs preserves QR pairing, discovery, selection and forgetting. Inbox preserves
notification settings and all reminder actions. Notes preserves cached search,
original-target queue status, retry and confirmed deletion.

Shared custom action/choice controls, icon tiles and content groups keep the visual
system maintainable. Native semantics, font scaling, IME handling and scrolling stay.
No new network services, remote assets or runtime dependencies are introduced.
