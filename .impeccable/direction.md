# Direction — Quiet clarity

User requested a from-scratch redesign using Apple Design, after rejecting the
forest identity and default-looking controls. Direct implementation is authorized.
Use restrained neutral surfaces, graphite type, blue actions, compact system
sans-serif and custom-shaped functional controls. Keep the first screen to a small
neyra wordmark beside the centered computer selector and a single Speak control.
All remaining features belong on secondary screens. Preserve speed, privacy,
Android accessibility and existing feature behavior. DESIGN.md and native source
are authoritative. Historical review images remain historical, not current evidence.
